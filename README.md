# eMERYTURA

Tracker inwestycji (plan rodzinny, IKE/IKZE, PPK) jako program na Windows.

## Jak pobrać
**Releases → latest**:
- `eMERYTURA-instalator.exe` – instalacja ze skrótem w menu Start (polecane),
- `eMERYTURA-portable.exe` – jeden plik, bez instalacji.

Każda zmiana w gałęzi `main` buduje nową wersję automatycznie (zakładka **Actions**).

## Dane
Zapisują się w profilu Windows (`%APPDATA%\eMERYTURA`), nie obok pliku EXE, więc aktualizacja ich nie kasuje. Kopię i tak rób przyciskiem eksportu w programie.

## Kod
- `app/index.html` – cała aplikacja.
- `main.js` – okno programu (Electron).
